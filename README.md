# bypas-key-aincrad


BYPASS KEY AINCRAD BY RAMA MODZ

######## HOW TO USE ########
UPLOAD ALL FILES TO GITHUB. AFTER UPLOADING THE FILES, GET THE GITHUB FILE LINK AND CONVERT THE GITHUB LINK TO RAW FORMAT. 

CONVERT THE GITHUB LINK TO RAW FORMAT USING THE FOLLOWING WEBSITE: https://git-rawify.vercel.app/ 

EXAMPLE
BEAFORE: https://github.com
AFTER: https://raw.githubusercontent.com 

AFTER CONVERTING TO RAW FORMAT, GET THE RAW LINK FROM ramascript.js AND ENCRYPT IT USING BASE64.
